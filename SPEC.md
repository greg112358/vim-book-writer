# Spec

A fast, lightweight desktop word processor for writing in [djot](https://djot.net), with vim controls.
Rust, custom-drawn (winit + wgpu + glyphon), macOS and Linux.

## How to use this file
Work top to bottom. Do the first unchecked item, then run `cargo test`, `cargo clippy --all-targets -- -D warnings`
and `cargo fmt --check`. Check the box only when the item's stated check passes.
Items marked **[visual]** can't be asserted by unit tests. Verify them by rendering offscreen to a PNG (a `--screenshot <path>`
flag that draws one frame of a given document and mode, then exits) and reading the image. Describe what you see in the
commit message. If the image looks wrong, fix it and re-render before checking the box.

## Product

**Modes.** Vim-style modal editing on a djot document (`.dj` files).
- **Normal mode:** the document renders. `**bold**` shows as bold with no asterisks, headings show as headings, and so on.
- **Insert mode:** the raw djot is visible, but styled. `**Bold Text**` shows the words in bold and the asterisks in a faint
  color, so the source stays readable while it's obvious what it will become.
- Visual mode selects text; the same formatting commands apply to the selection.

**Formatting.** Toolbar buttons and traditional shortcuts (Ctrl/Cmd+B, I, U, etc.) act on the current selection, or on the
word under the cursor if there is no selection.

**Toolbar.** Compact, dense, one thin row. Only things djot can express:
bold, italic, underline, strikethrough, font color, font name, font size, uppercase, headings, lists, quote, link,
save, export (Markdown/PDF), auto-save toggle.

**Font name, size and color** have no native djot syntax, so they use attributes on a span:
`[text]{style="color:#c00;font-size:14pt;font-family:Georgia"}`. Underline is
`[text]{style="text-decoration:underline"}`. Using `style` means HTML output works with no translation.
The **uppercase** button converts the selected characters to uppercase (an edit, not a style), so it survives export.

**Files.** Start screen shows "Open recent", "Open folder" and "Open file". `:w` and the Save button do the same thing.
An auto-save toggle saves after edits stop. Recent files and settings live in the OS config directory as TOML.

**File tree.** On the right side, modeled on Neo-tree, including its keys: `a` add, `d` delete, `r` rename, `c` copy,
`m` move, `y` yank name/path, `p` paste, `H` toggle hidden files, `R` refresh, `<CR>` open, `<Tab>`/`o` expand or preview,
`q` close. Respects `.gitignore`.

**Export.**
- **Markdown:** lossy. Anything CommonMark can't express (color, size, font, underline) is dropped; the text is kept.
- **PDF:** keeps all styling, generated by the app itself (no external tools).
- "Print" is the export action.

**Feel.** Fast to start, fast to type. Information-dense, not spacious: small controls, tight spacing, no large
buttons. Smooth scrolling and transitions. Continuous scroll layout with a fixed text column width, not paged.

## Decisions (already made, don't revisit)
- Layout: continuous scroll.
- Vim depth: solid core. Motions, operators, text objects (`ciw`, `di"`, `ap`), visual and visual-line, registers,
  dot-repeat, undo/redo, search (`/`, `n`, `N`), `:w` `:q` `:wq`. No macros, marks, visual-block, or `:s`/`:g`.
- Djot scope for v1: headings, paragraphs, emphasis/strong, strikethrough, links, lists, blockquotes, code,
  thematic break, attributes. No images, tables, footnotes, math, definition lists, task lists, or divs yet.
- Export: Markdown and PDF only.
- Parsing: the `jotdown` crate. PDF: the `printpdf` crate.
- The `vi` feature on cosmic-text covers only basic vim. Build the modal layer in this repo, reusing `modit` where it
  helps, and extend it to the scope above.

## Milestone 1: Headless core (testable, no window)

### Document and editing
- [x] Document open/save/word count (`src/document.rs`)
- [x] Config load/save with defaults (`src/config.rs`)
- [x] Directory listing that respects .gitignore (`src/files.rs`)
- [x] Fuzzy filter (`src/finder.rs`)
- [x] Text buffer with insert, delete, and cursor movement; tested without a window
- [x] Undo/redo over the buffer; tests cover undo after insert, delete, and multi-step redo
- [x] Find in document returning match ranges; tests cover no-match and multiple matches

### Djot model
- [x] Add `jotdown`. Parse a document into styled spans that keep source byte ranges; tests for headings, lists,
      blockquote, code, links, emphasis, strong, strikethrough, and nested emphasis
- [x] Parse `{style="..."}` attributes into structured style (color, font-size, font-family, underline); tests include
      malformed values, which must be ignored without panicking
- [x] Insert-mode styling map: for a source range, produce which characters are content and which are markup
      delimiters (so the renderer can draw delimiters faint); tests for `**bold**`, `_italic_`, `[text]{style="..."}`
- [x] Normal-mode rendering map: same input, but with delimiters and attribute blocks hidden; tests confirm the visible
      text of `**bold** and _it_` is `bold and it`

### Formatting commands
- [x] Toggle bold/italic/strikethrough over a selection: wraps with the delimiters, and removes them if already applied
- [x] Toggle underline via a style span
- [x] Apply font color, size, and name via a style span; merge into an existing span instead of nesting a new one
- [x] Uppercase the selection
- [x] With no selection, formatting applies to the word under the cursor
- [x] Each formatting command is one undo step

### Vim engine
- [x] Modes: normal, insert, visual, visual-line, with correct transitions (`i a o O A I`, `v V`, `Esc`)
- [x] Motions: `h j k l w b e 0 $ ^ gg G` and counts (`3w`)
- [x] Operators: `d c y` with motions, doubled forms (`dd cc yy`), `x`, `p P`, `u`, `Ctrl-r`
- [x] Text objects: `iw aw ip ap i" a" i( a(`
- [x] Registers: unnamed, named (`"a`), and yank/paste through them
- [x] Dot-repeat (`.`) for the last change
- [x] Search: `/`, `?`, `n`, `N`
- [x] Ex commands: `:w`, `:q`, `:wq`, `:q!`; `:w` triggers the same code path as the Save button
- [ ] Visual selection then a formatting shortcut applies the format to the selection

### Project, files, export
- [ ] Recent files list: add, dedupe, cap at 20, persist to TOML; tests for ordering and persistence
- [ ] Auto-save state machine: saves after N ms of no edits, not while nothing changed; tested with a fake clock
- [ ] File tree model with Neo-tree operations (add, delete, rename, copy, move, yank path, paste, toggle hidden);
      tests use a temp directory
- [ ] Export djot to Markdown; tests confirm color/size/font/underline are dropped and text is kept
- [ ] Export djot to PDF with `printpdf`; tests confirm a valid PDF is produced and text appears in it
